The idea

A companion you can talk to, not a chatbot you configure.

Moco started as a landing-page concept and has grown into a working prototype — a Streamlit app backed by the Groq API, with conversation memory stored in SQLite. It's an early build (v0.1), made to explore what a genuinely conversational AI companion could feel like. Still a work in progress, not a finished product.

Personality

Shaped through conversation design, not a scripted character.

Moco's tone comes from prompt and system design rather than a fixed script — right now that means a consistent, calm conversational voice, tuned through iteration on how it responds. It's a starting point, with room to become more distinct as the project develops.

Memory

Keeps track of what you've told it.

Conversations are stored in a database, so Moco can reference things said earlier in a chat instead of starting fresh every time. It's straightforward persistence, not some deep model of who you are — a foundation to build further memory features on top of.
